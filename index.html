OVERVIEWSUSTAINED EMBODIED AGENCY

Overview

A household task keeps changing as an agent acts. A new observation must be remembered. A physical action can hide an object. An unexpected outcome calls for another look.

RoboWeave studies how four agentic capabilities remain effective as their demands persist and interact within the same episode.

01 / BENCHMARKFROM BASIC ACTIONS TO COORDINATION

The RoboWeave benchmark

240 tasks built on BEHAVIOR in a humanoid setting. The same observation and action interface spans the full hierarchy.

L0100 tasks

Basic interaction

Establish the execution substrate: navigate, look, pick, place, open, and close.

MOVE→PICK→PLACE
The interaction foundation

Capability-focused

Make one primary demand the focus, with 30 tasks for each of the four capabilities.

AMPV
One primary demand per task
L220 tasks

Structured interplay

Bring two or three capability demands together within one evolving episode.

AMP
Sustained coordination in one episode

Controlled variants change task-relevant evidence, interaction history, physical conditions, or execution outcomes. L1 tasks still involve supporting capabilities.

05 / SHARED INTERFACE20 INTERMEDIATE ACTION PRIMITIVES

A shared action interface

Abstract low-level motor execution while preserving the agent’s task-level spatial and physical decisions.

Manipulate

Pick and place objects while accounting for their spatial relations.

Change the state

Open, close, and toggle to interact with the household environment.

Observe and navigate

Move, turn, and look to acquire information and reach the next action.

Shared observations

One head-camera and two wrist-camera RGB views, with observations, actions, and receipts from the five most recent completed steps.

Shared action interface

Temporary visual markers select visible targets while leaving task-level choices to the agent.

World-state verification

An environment-side verifier checks the final state. An agent’s declaration of completion is not itself success.
